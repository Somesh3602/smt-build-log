# Tools

Source code for the tools in the build log goes here, one folder per tool:

- `stocktake/` — StockTake Pro (also live at somesh142.github.io/Stock-Take)
- `price-tag-printer/` — Python ESC/POS print server and price-check pages
- `pricelynk-sheets/` — Apps Script backend, admin portal and staff printer
- `unload-tally/` — container unloading and outlet split tool
- `transfer-pdf/` — offline photo-to-transfer-PDF app

Before adding code, remove API keys, passwords, spreadsheet IDs and any customer data.
